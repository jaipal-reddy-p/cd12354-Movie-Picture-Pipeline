# 🎬 Movies App – CI/CD Project

## About the Project

This project is a Movies Application deployed using a **CI/CD pipeline**.

The application has a frontend and backend. The CI/CD pipeline automatically builds, tests, and deploys the application when changes are pushed to GitHub.

### Technologies Used

- Frontend: React.js
- Backend: Spring Boot
- CI/CD: GitHub Actions
- Infrastructure: Terraform
- Version Control: Git & GitHub
